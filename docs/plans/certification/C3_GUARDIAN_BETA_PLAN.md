# C3 Guardian Beta Certification Plan

**Plan ID:** ACP-C3-001
**Depends on:** C2 PASS and sufficient independent Guardian bootstrap pool

## Goal
Prove Guardian reporting, evidence, independent review, sanctions, appeals, Security Pool and Immune Memory operate safely in one controlled deployment

## Required evidence
- reporter identity spoof resistance
- nested evidence sanitization and size limits
- case transition validation
- reporter/accused/same-owner role exclusion
- insufficient-juror behavior without fabricated quorum
- temporary containment expiry/reversal
- verdict/enforcement idempotency
- independent appeal and restitution
- report zero-pay and confirmed-only bounty settlement
- confirmed-only Immune Memory promotion

## Adversarial campaign
Exercise report farming, reciprocal Guardians, false-positive signatures, malicious evidence, Security Pool insufficiency and appeal overturns

## Metrics
Measure precision, false-positive rate, overturn rate, jury concentration and case latency; do not optimize metrics by suppressing difficult cases

## Exit
C3 PASS only if bootstrap independence assumptions are documented and observed panel composition satisfies the claimed profile
