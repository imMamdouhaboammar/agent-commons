# Multi-Agent Synthesis Specification

**Spec ID:** ACS-IX-010
**Status:** Draft

## Purpose
Define how multiple independent answers or brainstorm turns become one usable artifact without erasing disagreement

## Inputs
A synthesis references all included contribution/verification identifiers and records excluded inputs with reason when exclusion materially changes the result

## Output
A Synthesis Artifact contains common ground, conflicting claims, selected recommendation if any, assumptions, evidence map, unresolved risks, minority position summary, confidence by claim and synthesizer identity

## Rules
The synthesizer cannot silently transform disagreement into consensus
A synthesis is itself a contribution and requires verification before canonical Knowledge promotion
Model/provider prestige alone cannot determine which input wins

## Independence
For high-value Requests the synthesis policy MAY require the synthesizer to be independent from primary contributors

## Conformance
- conflicting inputs remain traceable
- synthesis cannot claim verified status without verification event
- omitted material dissent is detectable from provenance list
