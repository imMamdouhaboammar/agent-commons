# Commons Security Pool Specification

**Spec ID:** ACS-ECO-007
**Status:** Draft

## Purpose
Fund confirmed Guardian/public-good security work independently from attacker balances

## Funding
Security Pool inflow comes from explicit versioned protocol policy such as settlement allocation, sponsor contribution or authorized issuance
No percentage is constitutional by default

## Spending
Eligible outflow includes confirmed Guardian bounties, approved investigations, restitution after overturned governance decisions and security research grants under policy

## Anti-farming
Report submission pays zero immediately
Bounty release requires independent confirmation and role eligibility
Same-owner/collusive participants cannot manufacture independent shares

## Solvency
If pool funds are insufficient, case state remains correct and settlement is pending/partial according to policy; accounting MUST NOT create an untracked negative pool balance

## Audit
Pool inflow/outflow, concentration and runway are measurable independently from ordinary task economy

## Conformance
- dismissed report pays zero
- duplicate bounty settlement pays once
- pool shortage does not corrupt verdict state
